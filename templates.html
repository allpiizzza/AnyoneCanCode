범용 프롬프트 템플릿

AI에게 "게시판 만들어줘"라고 하면 게시판 비슷한 게 나옵니다. 원하는 게 나오지 않는 이유는 대부분 AI가 부족해서가 아니라, 우리가 무엇을 원하는지 덜 말했기 때문이에요. 아래 4칸을 채우는 습관만 들이면 결과물의 품질이 눈에 띄게 달라집니다.

단계의미안 쓰면 생기는 일
[역할] AI가 어떤 입장에서 답할지 정해줍니다. "웹 개발자", "초등학생도 이해하게 설명하는 선생님"처럼요. 일반적이고 두루뭉술한 답이 옵니다.
[상황/맥락] 지금 뭘 만들고 있고, 어디까지 왔는지 설명합니다. AI가 처음부터 다시 분석해서, 방금까지 잘 되던 것도 같이 바뀝니다.
[요청] 원하는 걸 한 문장으로. 그리고 구체적인 조건을 번호로 나눠서. 내가 상상한 것과 다른 게 나옵니다. 가장 흔한 실패 원인.
[형식] 결과를 어떤 모양으로 받을지. "전체 코드 파일로", "단계별로", "표로". 코드 조각만 와서 어디에 붙여야 할지 알 수 없습니다.

예시

[역할] 너는 초보자에게 친절하게 설명하는 웹 개발자야.

[상황/맥락] 나는 지금 독서모임 책후기 게시판을 만들고 있어. 아직 목록 페이지밖에 없어.

[요청] 1. 목록 페이지의 각 카드에 마우스를 올리면 카드가 살짝 위로 떠오르는 효과를 넣고 싶어.
색이 갑자기 바뀌는 건 싫고, 부드럽게 움직였으면 좋겠어.
2. 상세 후기 페이지를 만들고 싶어. 목록 페이지를 클릭하면 상세 페이지로 넘어가면 돼

[형식] 수정된 CSS 전체 코드로 다시 주고,
어느 부분을 왜 고쳤는지 두세 줄로 설명해줘.
✱ 오늘 가장 많이 쓸 한 문장

"수정된 전체 코드로 다시 줘." — 비개발자에게는 "12번째 줄을 이렇게 고치세요"보다 파일 통째로 받아서 갈아끼우는 게 훨씬 안전합니다. [형식] 칸에 이 문장을 넣는 습관을 들이세요.
