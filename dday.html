🎤 진행자용 당일 아침에 훑기

당일 진행

순서 · 준비물 · 멈춰서 확인할 지점

전날 준비는 준비 체크리스트에서 끝났다고 보고, 여기서는 워크샵 당일에 무엇을 어떤 순서로 하는지만 다룹니다. 진행자가 아침에 한 번 훑고 시작하세요.

누가주로 진행자. 참가자가 봐도 되지만 필수는 아닙니다.
언제워크샵 당일 아침
총 시간2~3시간 (15 + 20 + 45 + 30 + 20분 + 나머지)

1. 시작 전 준비물

완성본 URL — 화면에 띄워두고 시작
이 사이트 주소 — 단톡방에 다시 한 번 공유
Sheets 템플릿 링크 (사본 만들기 권한 열려 있는지 확인)
주제 예시 표 — STEP 1 시작할 때 띄울 것
진행자 웹앱 URL — STEP 2에서 막힌 사람에게 공유할 백업

2. 계정 세팅 순서

전날 못 만들고 온 사람이 반드시 있습니다. 이 순서대로 다 함께 진행하세요. 순서가 중요합니다 — Vercel은 GitHub 계정이 있어야 합니다.

Replit 가입 — Google 계정으로 로그인하면 가장 빠릅니다
GitHub 로그인 확인 — 비밀번호 기억 안 나는 사람이 꼭 한 명 나옵니다
Vercel 가입 — 반드시 "Continue with GitHub"로
Google Sheets 템플릿 사본 만들기 (파일 → 사본 만들기)
⚠ Replit 결제 화면은 닫으라고 미리 말해주세요

가입 직후 유료 플랜을 권하는 화면이 뜹니다. 비개발자는 여기서 "결제해야 하나요?" 하고 멈춥니다. "뜨면 그냥 닫으세요. 오늘 안 씁니다"를 시작 전에 한 번 말해두면 문의가 사라집니다.

3. 진행 대본

구간마다 무엇을 하고 무엇을 말할지입니다. 각 문서 맨 아래 🎤 상자에 더 자세한 운영 요령이 있습니다.

시간할 일이 말은 꼭
15분 완성본 시연 → 세 단어(프론트·백·배포) 설명
README		 "오늘 코딩은 안 배웁니다. 말로 부탁하는 법을 배웁니다."
20분 계정 3종 확인 (Replit · GitHub · Vercel) "Vercel은 반드시 Continue with GitHub으로 가입하세요."
45분 주제 고르기(2분) → 화면 세 개 만들기
STEP 1		 "주제는 2분 안에. 안 떠오르면 기본으로."
"옆 사람과 화면이 달라도 정상입니다."
30분 Google Sheets 연동
STEP 2		 "여기서 절반은 한 번 막힙니다. 정상입니다."
20분 GitHub + Vercel 배포
STEP 3		 "다 함께 한 단계씩 갑니다. 먼저 가지 마세요."
나머지 커스터마이징 · Q&A · 주소 공유
여유 과제		 "이 문서는 오늘 이후에도 그대로 남아 있습니다."

4. 멈춰서 확인할 네 지점

6명이 각자 다른 속도로 갑니다. 아래 네 곳에서 "다 되신 분 손 들어주세요"를 한 번씩 하면, 뒤처진 사람이 조용히 포기하는 걸 막을 수 있습니다.

  • 1

    계정 생성 후

    Replit · GitHub · Vercel 세 개 모두 로그인 됐는지

  • 2

    화면 완료 후 (STEP 1)

    목록 · 글쓰기 · 상세보기 세 화면이 눈에 보이는지

  • 3

    Sheets 연동 후 (STEP 2)

    글을 하나 쓰면 스프레드시트에 행이 늘어나는지

  • 4

    배포 후 (STEP 3)

    각자의 .vercel.app 주소로 실제 접속되는지 — 휴대폰으로도

🎤 시간이 밀릴 때 자르는 순서

2~3시간은 생각보다 빠듯합니다. 밀리면 이 순서로 줄이세요.

  • 1순위로 자를 것 — 여유 과제. 원래 남는 시간용입니다.
  • 2순위 — STEP 1의 커스터마이징. 화면 세 개만 뜨면 다음으로 넘어갑니다.
  • 3순위 — STEP 2의 개별 해결. 진행자 웹앱 URL을 공유해 다 같이 같은 시트를 쓰게 하고 넘어갑니다.
  • 절대 자르지 말 것 — STEP 3 배포. 내 주소가 생기고 휴대폰에서 열리는 순간이 오늘의 하이라이트입니다. 여기까지 못 가면 만족도가 확 떨어집니다.

그리고 대신 고쳐주지 마세요. 막힌 사람 옆에서 "그걸 AI한테 뭐라고 말하면 될까요?"라고 되물어주는 게 오늘의 학습 목표에 맞습니다. 자세한 대응 원칙은 에러 해결법 맨 아래에 있습니다.
