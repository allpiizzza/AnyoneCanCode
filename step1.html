STEP 1 45분 AI 프롬프트

화면(UI) 만들기

눈에 보이는 것부터 만듭니다

저장이나 배포는 아직 생각하지 마세요. 지금 할 일은 화면 세 개를 눈으로 보는 것입니다. 목록, 글쓰기, 상세보기. 데이터는 가짜여도 됩니다. 화면이 먼저 있어야 "여기에 진짜 글이 들어가면 되겠구나"가 상상돼요.

아래 프롬프트를 그대로 복사해서 붙여넣으세요

step1-prompt.txt
HTML, CSS, JavaScript로 간단한 게시판 웹사이트를 만들어줘.

기능은 다음과 같아:

1. 목록 페이지 (index.html)
   - 게시글 제목, 작성자, 작성일을 카드 형태로 나열
   - 각 카드를 클릭하면 상세 페이지로 이동

2. 글쓰기 페이지 (write.html)
   - 제목, 작성자, 내용을 입력하는 폼
   - "등록" 버튼

3. 상세보기 페이지 (detail.html)
   - 선택한 글의 제목, 작성자, 작성일, 내용을 보여줌

디자인은 깔끔하고 따뜻한 느낌으로, 파스텔톤 색상을 사용해줘.

지금은 데이터 저장 없이 화면 디자인만 먼저 만들어줘.
더미 데이터(예시 글 2~3개)를 넣어서 화면이 어떻게 보이는지 확인할 수 있게 해줘.

이 프롬프트가 잘 만들어진 이유

  • 파일 이름을 지정했습니다. index.html, write.html, detail.html. 이름을 안 정해주면 AI가 매번 다른 이름을 쓰고, 다음 단계에서 대화가 어긋납니다.
  • "지금은 저장 없이"라고 범위를 잘랐습니다. 한 번에 다 시키면 결과가 커지고, 어디가 잘못됐는지 찾기 어려워집니다.
  • 더미 데이터를 요청했습니다. 빈 화면은 잘 만들어졌는지 판단할 수가 없어요.
  • 분위기를 말로 표현했습니다. "파스텔톤", "따뜻한 느낌" 같은 단어면 충분합니다. 색상 코드는 몰라도 됩니다.

결과가 나오면 확인할 것

  • 1

    파일이 세 개 만들어졌나요?

    Replit 왼쪽 파일 목록에 index.html, write.html, detail.html이 보여야 합니다. 하나로 합쳐서 줬다면 "세 개의 파일로 분리해서 다시 줘"라고 요청하세요.

  • 2

    목록 화면에 카드가 보이나요?

    예시 글 2~3개가 카드로 떠 있어야 합니다. 아무것도 안 보이면 errors.html로 가세요.

  • 3

    카드를 누르면 상세 화면으로 넘어가나요?

    내용이 정확하지 않아도 괜찮습니다. 페이지가 바뀌기만 하면 성공이에요.

  • 4

    글쓰기 화면에 입력칸과 등록 버튼이 있나요?

    지금은 눌러도 아무 일도 안 일어나는 게 정상입니다. 저장 기능은 STEP 2에서 붙입니다.

마음에 안 들면 이렇게 고쳐 말하세요

step1-refine.txt
지금 화면 잘 나왔어. 여기서 딱 하나만 바꾸고 싶어.

(예시 — 하나만 골라서 쓰세요)
- 카드가 너무 작아. 좀 더 크고 여백이 넉넉했으면 좋겠어.
- 색이 차가워 보여. 크림색이랑 살구색 위주로 바꿔줘.
- 글씨가 작아서 잘 안 보여. 제목을 더 크게 해줘.
- 모바일에서 보면 카드가 잘려. 화면이 좁을 때 세로로 쌓이게 해줘.

나머지는 그대로 두고, 수정된 전체 코드로 다시 줘.
✱ 완성본을 참고 자료로 쓰세요

원하는 느낌을 말로 설명하기 어렵다면 완성본 데모를 열어두고 "이런 느낌으로"라고 말해도 됩니다. 화면을 캡처해서 AI에게 보여주는 것도 좋은 방법이에요.
