STEP 1 45분 AI 프롬프트

화면(UI) 만들기

눈에 보이는 것부터 만듭니다

지금 할 일은 딱 하나입니다. 화면 세 개를 눈으로 보는 것. 목록, 글쓰기, 상세보기. 저장도 배포도 아직 생각하지 마세요.

할 일아래 다섯 단계를 순서대로 따라갑니다. 1 → 2 → 3 → 4 → 5.
시간45분
끝나면화면 세 개가 뜹니다. 단, 새로고침하면 글이 사라집니다 — 정상입니다.

1. 무엇을 만들지 고르기

완성본 데모는 책후기 게시판이지만, 여러분은 원하는 주제로 만들면 됩니다. 만드는 방법은 무엇을 고르든 똑같아요. 오늘 배우는 건 "게시판 만드는 법"이 아니라 "무엇이든 만드는 법"이니까요.

✱ 고르는 기준은 하나뿐입니다

기록하고 싶은 것 하나가 네 칸으로 적히면 됩니다. 아래 예시를 보면 감이 올 거예요.

사전 안내를 보고 미리 생각해오셨다면 그걸 그대로 쓰시면 됩니다. 네 칸만 다시 확인하고 2단계로 넘어가세요.

주제네 칸에 무엇이 들어가나어떤 화면이 되나
📚 책·영화 후기
(기본)		 제목 · 작성자 · 작성일 · 내용 후기 카드가 쌓이는 목록
⭐ 별점 랭킹
(맛집·카페·책 뭐든)		 대상 · 추천인 · 별점 · 한줄평 별점이 붙은 목록. 1위가 생깁니다
🎨 오늘의 기분 날짜 · 이름 · 기분(이모지) · 한 줄 색깔 타일이 채워지는 벽
💰 회비·지출 장부 날짜 · 이름 · 항목 · 금액 합계가 맨 위에 뜨는 목록
❓ 오늘의 질문 날짜 · 이름 · 질문 · 답 질문과 답이 붙은 카드
✍️ 직접 정하기 ○○ · ○○ · ○○ · ○○ 기록하고 싶은 게 있다면 그걸로
⚠ 2분 안에 정하세요

고민이 길어지면 만들 시간이 줄어듭니다. 안 떠오르면 기본(책후기 게시판)으로 가세요. 오늘 목표는 완벽한 아이디어가 아니라 내 주소가 있는 사이트 하나입니다. 주제는 나중에 얼마든지 바꿀 수 있어요.

2. StackBlitz 열고 파일 세 개 만들기

StackBlitz는 브라우저 안의 작업실입니다. 설치할 것도, 저장 버튼을 누를 일도 없어요. 주소창에 stackblitz.com을 치고 Sign in → Continue with GitHub으로 들어갑니다.

⚠ 반드시 GitHub 계정으로 로그인하세요

이메일로 따로 가입하면 STEP 3에서 저장소를 만들 때 다시 연결해야 합니다. 지금 GitHub으로 들어가 두면 그 과정이 통째로 없어져요.

새 프로젝트 만들기

  • 1

    대시보드에서 New Project

    로그인하면 내 프로젝트 목록(대시보드)이 나옵니다. 파란 New Project 버튼을 누르세요.

  • 2

    스타터 목록에서 HTML/CSS/JS 고르기

    여러 카드가 뜹니다. React·Angular·Vue 같은 건 오늘 필요 없어요. HTML/CSS/JS(정적 웹) 하나만 고릅니다.

    안 보이면 위쪽 카테고리에서 Frontend를 눌러보세요.

  • 3

    제목을 알아볼 이름으로 바꾸기

    위쪽 가운데 프로젝트 제목을 눌러 book-review처럼 영문 소문자로 바꿔둡니다. 나중에 저장소 이름이 될 자리예요.

⛔ 지름길 주소를 검색해서 쓰지 마세요

인터넷에 도는 stackblitz.com/fork/... 같은 주소는 남이 만들어둔 엉뚱한 프로젝트가 복제됩니다. 실제로 /fork/html은 이름만 html이고 내용은 Angular 프로젝트예요. 꼭 대시보드의 New Project에서 시작하세요.

화면은 세 덩어리입니다

처음 열면 복잡해 보이지만, 오늘 쓸 곳은 세 군데뿐입니다. 나머지는 눈길도 주지 마세요.

✱ Run 버튼이 없습니다 — 고장이 아니에요

StackBlitz는 타이핑을 멈추면 오른쪽 미리보기가 알아서 갱신됩니다. 저장도 자동이라 누를 게 없어요. 화면이 안 바뀌는 것 같으면 미리보기 위쪽의 새로고침(↻)만 한 번 눌러보세요.

파일 세 개 만들기

왼쪽 파일 목록 위의 새 파일 아이콘을 눌러 아래 세 개를 만듭니다. index.html은 이미 있을 테니 그대로 쓰고 두 개만 새로 만들면 됩니다.

만들 파일 세 개
index.html
write.html
detail.html

스타터에 딸려온 style.css나 script.js가 있어도 지우지 말고 그냥 두세요. 나중에 AI가 준 코드로 덮어쓰거나, 안 쓰면 그만입니다.

⚠ 이름을 정확히 그대로

전부 영문 소문자입니다. Index.html은 index.html과 다른 파일로 취급돼요. 나중에 "글쓰기 페이지 고쳐줘"라고 말했을 때 AI가 어느 파일인지 알아야 하니, 이름을 맞춰두는 게 중요합니다.

3. 프롬프트를 AI에게 붙여넣기

기본(책후기 게시판)으로 간다면 아래 상자의 COPY를 누르고 그대로 붙여넣으면 됩니다. 한 글자도 바꾸지 않아도 돼요.

step1-prompt.txt
HTML, CSS, JavaScript로 간단한 게시판 웹사이트를 만들어줘.

기능은 다음과 같아:

1. 목록 페이지 (index.html)
   - 게시글 제목, 작성자, 작성일을 카드 형태로 나열
   - 각 카드를 클릭하면 상세 페이지로 이동

2. 글쓰기 페이지 (write.html)
   - 제목, 작성자, 내용을 입력하는 폼
   - "등록" 버튼

3. 상세보기 페이지 (detail.html)
   - 선택한 글의 제목, 작성자, 작성일, 내용을 보여줌

디자인은 깔끔하고 따뜻한 느낌으로, 파스텔톤 색상을 사용해줘.

지금은 데이터 저장 없이 화면 디자인만 먼저 만들어줘.
더미 데이터(예시 글 2~3개)를 넣어서 화면이 어떻게 보이는지 확인할 수 있게 해줘.
＋ 다른 주제를 고르셨다면 — 프롬프트 바꿔 쓰기

○○ 자리를 1단계에서 정한 네 칸으로 바꿔서 쓰세요. 나머지 문장은 그대로 두는 게 좋습니다.

step1-prompt-custom.txt
HTML, CSS, JavaScript로 간단한 ○○ 웹사이트를 만들어줘.

기능은 다음과 같아:

1. 목록 페이지 (index.html)
   - ○○, ○○, ○○을 카드 형태로 나열
   - 각 카드를 클릭하면 상세 페이지로 이동

2. 글쓰기 페이지 (write.html)
   - ○○, ○○, ○○, ○○을 입력하는 폼
   - "등록" 버튼

3. 상세보기 페이지 (detail.html)
   - 선택한 항목의 ○○, ○○, ○○, ○○을 보여줌

디자인은 ○○한 느낌으로 만들어줘.

지금은 데이터 저장 없이 화면 디자인만 먼저 만들어줘.
더미 데이터(예시 2~3개)를 넣어서 화면이 어떻게 보이는지 확인할 수 있게 해줘.

채워 쓴 예 — 맛집 별점 랭킹으로 만든다면

example-rating.txt
HTML, CSS, JavaScript로 간단한 맛집 별점 랭킹 웹사이트를 만들어줘.

기능은 다음과 같아:

1. 목록 페이지 (index.html)
   - 가게 이름, 추천인, 별점(★ 1~5개)을 카드 형태로 나열
   - 별점이 높은 순서로 정렬해서 보여줘
   - 각 카드를 클릭하면 상세 페이지로 이동

2. 글쓰기 페이지 (write.html)
   - 가게 이름, 추천인, 별점, 한줄평을 입력하는 폼
   - 별점은 ★을 눌러서 1~5개 중에 고를 수 있게 해줘
   - "등록" 버튼

3. 상세보기 페이지 (detail.html)
   - 선택한 가게의 이름, 추천인, 별점, 한줄평을 보여줌

디자인은 깔끔하고 따뜻한 느낌으로 만들어줘.

지금은 데이터 저장 없이 화면 디자인만 먼저 만들어줘.
더미 데이터(예시 2~3개)를 넣어서 화면이 어떻게 보이는지 확인할 수 있게 해줘.

"별점이 높은 순서로 정렬"처럼 주제에 맞는 조건 한 줄을 덧붙이면 결과가 확 달라집니다. 회비 장부라면 "맨 위에 합계 금액을 보여줘", 기분 벽이라면 "기분에 따라 카드 색이 달라지게 해줘" 같은 식이에요.

＋ 이 프롬프트가 왜 이렇게 생겼는지 궁금하다면
  • 파일 이름을 지정했습니다. 안 정해주면 AI가 매번 다른 이름을 쓰고, 다음 단계에서 대화가 어긋납니다.
  • "지금은 저장 없이"라고 범위를 잘랐습니다. 한 번에 다 시키면 결과가 커지고, 어디가 잘못됐는지 찾기 어려워집니다.
  • 더미 데이터를 요청했습니다. 빈 화면은 잘 만들어졌는지 판단할 수가 없어요.
  • 분위기를 말로 표현했습니다. "파스텔톤", "따뜻한 느낌"이면 충분합니다. 색상 코드는 몰라도 됩니다.

이 네 가지가 범용 프롬프트 템플릿에서 말하는 네 칸입니다.

4. 받은 코드를 StackBlitz에 옮기기

오늘 가장 많이 반복하게 될 동작입니다. 세 번만 해보면 손에 익어요.

  • 1

    코드 블록의 복사 버튼을 누릅니다

    AI 답변의 코드 상자 오른쪽 위에 복사 버튼이 있습니다. 그걸 쓰세요. 드래그로 긁으면 설명 문장까지 섞여 들어갑니다.

  • 2

    해당 파일을 열고, 있던 내용을 전부 지웁니다

    Ctrl + A(맥은 Cmd + A)로 전체 선택. 반쯤 남은 옛 코드가 섞이는 게 가장 흔한 사고입니다.

  • 3

    붙여넣습니다

    저장은 자동입니다. 오른쪽 미리보기가 곧바로 바뀌는지 보세요. 파일 세 개를 각각 이렇게 채웁니다.

  • 4

    오른쪽 미리보기를 확인합니다

    누를 버튼은 없습니다. 붙여넣는 순간 화면이 바뀝니다. 안 바뀌면 미리보기 위쪽의 새로고침(↻)을 한 번 누르세요.

5. 화면 확인하기

아래 네 가지만 보면 됩니다. 코드는 읽지 않아도 돼요.

  • ✓

    파일이 세 개 만들어졌나요?

    왼쪽 목록에 index.html, write.html, detail.html이 보여야 합니다. 하나로 합쳐서 줬다면 "세 개의 파일로 분리해서 다시 줘"라고 하세요.

  • ✓

    목록 화면에 카드가 보이나요?

    예시 2~3개가 카드로 떠 있어야 합니다. 아무것도 안 보이면 에러 해결법으로 가세요.

  • ✓

    카드를 누르면 상세 화면으로 넘어가나요?

    내용이 정확하지 않아도 괜찮습니다. 페이지가 바뀌기만 하면 성공이에요.

  • ✓

    글쓰기 화면에 입력칸과 등록 버튼이 있나요?

    지금은 눌러도 아무 일이 없는 게 정상입니다. 저장은 STEP 2에서 붙입니다.

✱ 옆 사람과 화면이 달라도 정상입니다

같은 프롬프트를 넣어도 AI는 매번 조금씩 다르게 만듭니다. 세 화면이 뜨고 서로 이동되면 성공이에요. 색이나 모양은 지금부터 바꾸면 됩니다.

마음에 안 드는 곳 고치기

여기부터가 진짜 재미있는 부분입니다. 한 번에 하나씩만 바꾸세요.

step1-refine.txt
지금 화면 잘 나왔어. 여기서 딱 하나만 바꾸고 싶어.

(예시 — 하나만 골라서 쓰세요)
- 카드가 너무 작아. 좀 더 크고 여백이 넉넉했으면 좋겠어.
- 색이 차가워 보여. 크림색이랑 살구색 위주로 바꿔줘.
- 글씨가 작아서 잘 안 보여. 제목을 더 크게 해줘.
- 모바일에서 보면 카드가 잘려. 화면이 좁을 때 세로로 쌓이게 해줘.

나머지는 그대로 두고, 수정된 전체 코드로 다시 줘.
✱ 원하는 느낌을 말로 못 하겠다면

완성본 데모를 열어두고 "이런 느낌으로"라고 해도 됩니다. 화면을 캡처해서 AI에게 보여주는 것도 좋은 방법이에요.

자주 나오는 질문

AI가 파일을 하나로 합쳐서 줬어요

"HTML, CSS, JavaScript를 세 개의 파일로 분리해서 다시 줘. 파일 이름은 index.html, write.html, detail.html로 해줘"라고 하면 됩니다.

미리보기가 하얗게 비어 있어요
  • 파일 이름이 index.html이 맞는지
  • 붙여넣을 때 앞부분이 잘리지 않았는지 — 첫 줄이 <!DOCTYPE html>로 시작해야 합니다
  • 미리보기 창을 한 번 새로고침

그래도 안 되면 에러 해결법으로 가세요.

글쓰기에서 등록을 눌러도 아무 일이 없어요

지금은 그게 정상입니다. 저장 기능을 아직 안 붙였으니까요. STEP 2에서 붙입니다.

AI가 갑자기 코드를 크게 바꿔놨어요

"방금 준 코드는 취소하고, 직전 버전으로 돌아가서 내가 말한 것만 바꿔줘"라고 하세요. 다음부터는 요청 끝에 "나머지는 그대로 두고"를 붙이면 크게 줄어듭니다.

StackBlitz에서 결제하라는 화면이 떠요

닫으셔도 됩니다. 오늘 StackBlitz는 코드를 붙여넣고 화면을 보는 용도로만 씁니다. 유료가 필요한 건 비공개(private) 저장소인데, 오늘 만드는 저장소는 공개(public)라 무료 범위 안입니다. AI도 별도 채팅창에서 쓰니 관계없어요.

🎤 진행자용 — 45분 운영 방법
  • 0~3분 · 주제 고르기. 예시 표를 화면에 띄우고 "2분 드릴게요"라고 시간을 잘라주세요. 못 고른 사람은 기본으로 보냅니다.
  • 3~8분 · StackBlitz 화면 세 덩어리를 화면 공유로 같이 봅니다. New Project → HTML/CSS/JS와 파일 만들기를 한 번은 같이 해보세요. "Run 버튼이 없다"는 말을 미리 해두면 질문이 확 줄어듭니다.
  • 8~18분 · 프롬프트를 복사해 각자 실행. 주제를 바꾼 사람은 ○○를 채웠는지 봐주세요. 진행자는 돌아다니며 "파일 세 개 만들어졌는지"만 확인합니다.
  • 18~28분 · 5단계 확인 항목을 같이 짚습니다. 여기서 손 들어 확인을 한 번 하세요.
  • 28~45분 · 각자 하나씩 고치기. 빨리 끝낸 사람에게는 "카드에 마우스 올리면 떠오르게" 같은 과제를 주면 좋습니다.

대신 고쳐주지 마세요. 막힌 사람 옆에서 "그걸 AI한테 뭐라고 말하면 될까요?"라고 되물어주는 게 오늘의 학습 목표에 맞습니다.

시작 전에 한 번 말해주면 좋은 것 — "결제하라는 화면이 뜨면 닫으세요. 오늘 안 씁니다."

주제가 6명 다 달라도 괜찮습니다. 네 칸 구조가 같아서 막히는 지점도 똑같습니다. 오히려 마지막에 서로 구경하는 재미가 생겨요.
