STEP 1 45분 AI 프롬프트

화면(UI) 만들기

눈에 보이는 것부터 만듭니다

1. 무엇을 만들지 고르기

완성본 데모는 책후기 게시판이지만, 여러분은 원하는 주제로 만들면 됩니다. 만드는 방법은 무엇을 고르든 똑같아요.
오늘 배우는 건 "게시판 만드는 법"이 아니라 "무엇이든 만드는 법"이니까요.

✱ 고르는 기준은 하나뿐입니다

기록하고 싶은 것 하나를 4개로 상세화하면 됩니다. 아래 예시를 보면 감이 올 거예요.

주제네 칸에 무엇이 들어가나어떤 화면이 되나
📚 책·영화 후기
(기본)		 제목 · 작성자 · 작성일 · 내용 후기 카드가 쌓이는 목록
⭐ 별점 랭킹
(맛집·카페·책 뭐든)		 대상 · 추천인 · 별점 · 한줄평 별점이 붙은 목록. 1위가 생깁니다
🎨 오늘의 기분 날짜 · 이름 · 기분(이모지) · 한 줄 색깔 타일이 채워지는 벽
💰 회비·지출 장부 날짜 · 이름 · 항목 · 금액 합계가 맨 위에 뜨는 목록
❓ 오늘의 질문 날짜 · 이름 · 질문 · 답 질문과 답이 붙은 카드
✍️ 직접 정하기 ○○ · ○○ · ○○ · ○○ 기록하고 싶은 게 있다면 그걸로
⚠ 2분 안에 정하세요

고민이 길어지면 만들 시간이 줄어듭니다. 안 떠오르면 기본(책후기 게시판)으로 가세요. 오늘 목표는 완벽한 아이디어가 아니라 내 주소가 있는 사이트 하나입니다. 주제는 나중에 얼마든지 바꿀 수 있어요.

2. StackBlitz 열고 프로젝트 만들기

StackBlitz는 브라우저 안의 작업실입니다.
주소창에 stackblitz.com을 치고 Sign in → Continue with GitHub으로 들어갑니다.

⚠ 반드시 GitHub 계정으로 로그인하세요

이메일로 따로 가입하면 STEP 3에서 저장소를 만들 때 다시 연결해야 합니다.
지금 GitHub으로 들어가 두면 그 과정이 통째로 없어져요.

새 프로젝트 만들기

  • 1

    대시보드에서 New Project

    로그인하면 내 프로젝트 목록(대시보드)이 나옵니다. 파란 New Project 버튼을 누르세요.

  • 2

    스타터 목록에서 Vanilla(Javascript) 고르기

    안 보이면 위쪽 카테고리에서 Frontend를 눌러보세요.

  • 3

    제목을 알아볼 이름으로 바꾸기

    위쪽 가운데 프로젝트 제목을 눌러 book-review처럼 영문 소문자로 바꿔둡니다. 나중에 저장소 이름이 될 자리예요.

화면은 세 덩어리입니다

처음 열면 복잡해 보이지만, 오늘 쓸 곳은 세 군데뿐입니다.

수정 후 자동으로 미리보기에 적용됩니다.

StackBlitz는 타이핑을 멈추면 오른쪽 미리보기가 알아서 갱신됩니다. 저장도 자동이라 누를 게 없어요. 화면이 안 바뀌는 것 같으면 미리보기 위쪽의 새로고침(↻)만 한 번 눌러보세요.

3. AI가 먼저 묻게 하기

여기서부터가 오늘의 핵심입니다. 바로 "만들어줘"라고 하지 않습니다. 대신 AI에게 나한테 먼저 질문해 달라고 시킵니다.

✱ 왜 바로 안 시키나요

주제가 사람마다 다르니 필요한 것도 다릅니다. 내가 미처 생각 못 한 걸 AI가 물어봐 주면, 답만 하면서 계획이 세워집니다. 빈 화면 앞에서 "뭐라고 써야 하지" 하고 멈추는 시간이 사라져요.

아래를 복사해서 ○○ 두 군데만 1단계에서 정한 내 주제로 바꿔 넣으세요.

step1-interview.txt
[역할] 너는 초보자에게 친절하게 설명하는 웹 개발자야.

[상황/맥락] 나는 ○○을 기록하는 웹사이트를 만들려고 해.
기록할 항목은 ○○, ○○, ○○, ○○ 네 가지야. 코딩은 전혀 몰라.

[요청] 바로 코드를 주지 말고, 먼저 나한테 필요한 걸 물어봐 줘.
한 번에 서너 개씩만, 초보자도 답할 수 있는 쉬운 말로.
내가 답하면 그걸 정리해서 "무엇을 만들지" 계획을 보여줘.

[형식] 계획은 한 페이지 분량으로, 화면 목록과
각 화면에 무엇이 들어가는지 항목으로 정리해줘.

예를 들어 맛집 별점 랭킹이라면 첫 줄은 나는 맛집 별점을 기록하는 웹사이트를 만들려고 해, 항목은 가게 이름, 추천인, 별점, 한줄평이 됩니다.

질문이 오면 이렇게 답하세요

  • 1

    짧게 답해도 됩니다

    "별점은 별 다섯 개 중에 고르게", "정렬은 최신순" 정도면 충분합니다. 문장으로 안 써도 돼요.

  • 2

    모르면 모른다고 하세요

    "그건 잘 모르겠어. 네가 추천해줘." — 이 한마디면 AI가 알아서 정합니다. 오늘 가장 쓸모 있는 문장입니다.

  • 3

    계획이 오면 읽어보고 고칩니다

    마음에 안 드는 줄이 있으면 말로 고치세요. "상세 화면에 날짜도 보여줘" 같은 식으로요. 아직 코드가 아니라 계획이라 몇 번을 고쳐도 공짜입니다.

⚠ 여기서 오래 붙잡지 마세요

주고받기는 두세 번이면 충분합니다. 계획이 완벽할 필요는 없어요. 결과물이 나온 뒤에 다시 고치면 됩니다.

4. 계획대로 화면 만들어 달라고 하기

계획이 마음에 들면, 같은 대화창에 이어서 아래를 붙여넣습니다. 바꿀 곳이 없으니 그대로 복사하면 됩니다.

step1-build.txt
좋아, 이 계획대로 가자.

[요청] 계획 중에서 이번에는 화면만 먼저 만들어줘.
- 저장 기능은 아직 넣지 말고, 예시 2~3개를 넣어서
  화면이 어떻게 보이는지만 확인할 수 있게 해줘
- 디자인은 깔끔하고 따뜻한 느낌으로
- 맨 처음 열리는 화면의 파일 이름은 index.html로 해줘.
  나머지 파일 이름은 네가 알아서 정하고, 답변에 이름을 적어줘

[형식] 세 파일의 전체 코드로 줘.
✱ 이 짧은 요청이 하는 일 3가지
  • 범위를 잘랐습니다 — "이번에는 화면만". 저장까지 한 번에 시키면 결과가 길어져 어긋납니다
  • 예시 데이터를 요청했습니다 — 빈 화면은 잘 됐는지 판단할 수가 없어요
  • 형식을 정했습니다 — "전체 코드로". 조각으로 오면 어디 붙일지 모릅니다
＋ 주제를 못 정했거나 인터뷰가 막혔다면 — 바로 쓰는 프롬프트

인터뷰를 건너뛰고 이거 하나만 붙여넣어도 됩니다. 기본 주제(책후기 게시판)로 한 번에 끝냅니다. 먼저 화면을 뽑아놓고, 주제는 나중에 바꿔도 늦지 않아요.

step1-fallback.txt
HTML, CSS, JavaScript로 간단한 게시판 웹사이트를 만들어줘.

기능은 다음과 같아:

1. 목록 페이지
   - 게시글 제목, 작성자, 작성일을 카드 형태로 나열
   - 각 카드를 클릭하면 상세 페이지로 이동

2. 글쓰기 페이지
   - 제목, 작성자, 내용을 입력하는 폼
   - "등록" 버튼

3. 상세보기 페이지
   - 선택한 글의 제목, 작성자, 작성일, 내용을 보여줌

디자인은 깔끔하고 따뜻한 느낌으로, 파스텔톤 색상을 사용해줘.

지금은 데이터 저장 없이 화면 디자인만 먼저 만들어줘.
더미 데이터(예시 글 2~3개)를 넣어서 화면이 어떻게 보이는지 확인할 수 있게 해줘.

5. 받은 코드를 StackBlitz에 옮기기

오늘 가장 많이 반복하게 될 동작입니다. 세 번만 해보면 손에 익어요.

AI가 생성한대로 파일을 만듭니다.

파일 이름은 여러분이 정하지 않습니다. AI가 답변에서 파일마다 이름을 적어줍니다. 목록 페이지 (index.html)처럼요. 그 이름을 그대로 만들면 됩니다.

주제가 무엇이든 화면은 셋입니다 — 쌓인 걸 보는 목록, 새로 적는 입력, 하나를 자세히 보는 상세. 그래서 파일도 보통 셋이 옵니다.

왼쪽 파일 목록 위의 새 파일 아이콘을 눌러 만드세요. index.html은 이미 있을 테니 그대로 쓰고 나머지만 새로 만들면 됩니다.

⚠ 한 글자도 다르면 안 됩니다

AI가 적어준 이름을 보고 그대로 옮겨 적으세요. Write.html과 write.html은 다른 파일로 취급됩니다. 오타가 나면 화면끼리 이동이 안 돼요.

헷갈리면 AI에게 "만들어야 할 파일 이름만 목록으로 다시 알려줘"라고 물어보세요.

그다음 코드를 옮깁니다

  • 1

    코드 블록의 복사 버튼을 누릅니다

    AI 답변의 코드 상자 오른쪽 위에 복사 버튼이 있습니다. 그걸 쓰세요. 드래그로 긁으면 설명 문장까지 섞여 들어갑니다.

  • 2

    해당 파일을 열고, 있던 내용을 전부 지웁니다

    Ctrl + A(맥은 Cmd + A)로 전체 선택. 반쯤 남은 옛 코드가 섞이는 게 가장 흔한 사고입니다.

  • 3

    붙여넣습니다

    저장은 자동입니다. 오른쪽 미리보기가 곧바로 바뀌는지 보세요. 파일들을 각각 이렇게 채웁니다.

  • 4

    오른쪽 미리보기를 확인합니다

    누를 버튼은 없습니다. 붙여넣는 순간 화면이 바뀝니다. 안 바뀌면 미리보기 위쪽의 새로고침(↻)을 한 번 누르세요.

6. 화면 확인하기

아래 네 가지만 보면 됩니다. 코드는 읽지 않아도 돼요.

  • ✓

    파일이 다 잘 만들어졌나요?

    왼쪽 목록에 보여야 합니다.

  • ✓

    원하는 대로 구현이 모두 되었나요?

    예를 들어 목록 화면이 있고 클릭하면 상세 페이지가 넘어가거나, 등록할 수 있는 버튼이 있는지 등 기능들을 확인하세요

✱ 옆 사람과 화면이 달라도 정상입니다

주제도 다르고, 같은 요청을 넣어도 AI는 매번 조금씩 다르게 만듭니다. 색이나 모양은 지금부터 바꾸면 됩니다.

마음에 안 드는 곳 고치기

여기부터가 진짜 재미있는 부분입니다. 한 번에 하나씩만 바꾸세요.

step1-refine.txt
지금 화면 잘 나왔어. 여기서 딱 하나만 바꾸고 싶어.

(예시 — 하나만 골라서 쓰세요)
1. 카드가 너무 작아. 좀 더 크고 여백이 넉넉했으면 좋겠어.
2. 색이 차가워 보여. 크림색이랑 살구색 위주로 바꿔줘.
3. 글씨가 작아서 잘 안 보여. 제목을 더 크게 해줘.
4. 모바일에서 보면 카드가 잘려. 화면이 좁을 때 세로로 쌓이게 해줘.

나머지는 그대로 두고, 수정된 전체 코드로 다시 줘.
✱ 원하는 느낌을 말로 못 하겠다면

완성본 데모를 열어두고 "이런 느낌으로"라고 해도 됩니다. 화면을 캡처해서 AI에게 보여주는 것도 좋은 방법이에요.

자주 나오는 질문

AI가 파일을 하나로 합쳐서 줬어요

여러 메뉴들을 추가해서 기능을 확장할거야. 지금 1개의 파일로 만들어 준 걸 효율적으로 분리해서 다시 줘

미리보기가 하얗게 비어 있어요
  • 파일 이름이 index.html이 맞는지
  • 붙여넣을 때 앞부분이 잘리지 않았는지 — 첫 줄이 <!DOCTYPE html>로 시작해야 합니다
  • 미리보기 창을 한 번 새로고침

그래도 안 되면 에러 해결법으로 가세요.

글쓰기에서 등록을 눌러도 아무 일이 없어요

지금은 그게 정상입니다. 저장 기능을 아직 안 붙였으니까요. STEP 2에서 붙입니다.

AI가 갑자기 코드를 크게 바꿔놨어요

"방금 준 코드는 취소하고, 직전 버전으로 돌아가서 내가 말한 것만 바꿔줘"라고 하세요. 다음부터는 요청 끝에 "나머지는 그대로 두고"를 붙이면 크게 줄어듭니다.

StackBlitz에서 결제하라는 화면이 떠요

닫으셔도 됩니다. 오늘 StackBlitz는 코드를 붙여넣고 화면을 보는 용도로만 씁니다. 유료가 필요한 건 비공개(private) 저장소인데, 오늘 만드는 저장소는 공개(public)라 무료 범위 안입니다. AI도 별도 채팅창에서 쓰니 관계없어요.

🎤 진행자용 — 45분 운영 방법
  • 0~3분 · 주제 고르기. 예시 표를 화면에 띄우고 "2분 드릴게요"라고 시간을 잘라주세요. 끝까지 못 고른 사람은 4단계의 접힌 폴백 프롬프트로 보내면 됩니다 — 인터뷰를 건너뛰고 바로 화면이 나옵니다.
  • 3~8분 · StackBlitz 화면 세 덩어리를 화면 공유로 같이 봅니다. New Project를 한 번은 같이 해보세요. "Run 버튼이 없다"는 말을 미리 해두면 질문이 확 줄어듭니다.
  • 8~14분 · 3단계 인터뷰. ○○를 자기 주제로 채웠는지만 봐주세요. "모르겠으면 '네가 추천해줘'라고 답하세요"를 미리 크게 말해두면 여기서 멈추는 사람이 없습니다. 주고받기 두세 번에서 끊게 하세요 — 계획을 다듬느라 시간을 다 쓰는 사람이 꼭 나옵니다.
  • 14~22분 · 4단계 요청 → 코드 받기 → 파일 만들고 옮기기. 진행자는 돌아다니며 "파일 세 개에 각각 붙여넣었는지"만 확인합니다.
  • 22~28분 · 6단계 확인 항목을 같이 짚습니다. 여기서 손 들어 확인을 한 번 하세요.
  • 28~45분 · 각자 하나씩 고치기. 빨리 끝낸 사람에게는 "카드에 마우스 올리면 떠오르게" 같은 과제를 주면 좋습니다.

대신 고쳐주지 마세요. 막힌 사람 옆에서 "그걸 AI한테 뭐라고 말하면 될까요?"라고 되물어주는 게 오늘의 학습 목표에 맞습니다.

시작 전에 한 번 말해주면 좋은 것 — "결제하라는 화면이 뜨면 닫으세요. 오늘 안 씁니다."

주제가 6명 다 달라도 괜찮습니다. 네 칸 구조가 같아서 막히는 지점도 똑같습니다. 오히려 마지막에 서로 구경하는 재미가 생겨요.
