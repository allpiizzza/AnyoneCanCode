준비 체크리스트

항목을 클릭하면 취소선이 그어집니다

워크샵 당일에 시간을 잡아먹는 건 코딩이 아니라 계정 만들기와 로그인입니다. 아래 네 묶음만 미리 정리해두면 본 내용에 쓸 시간이 40분쯤 늘어납니다.

쓰는 사람주로 진행자. 참가자는 "2. 참가자 사전 공지"만 보면 됩니다.
언제1~2번은 워크샵 며칠 전, 3~4번은 당일 아침에 훑습니다.
기록체크한 항목은 이 브라우저에 저장됩니다. 상태바에 남은 개수가 표시돼요.

1. 진행자 사전 준비

완성본 예제 사이트 배포해두기 (시연용 URL 확보)
Google Sheets 템플릿 준비 — 컬럼 [제목, 작성자, 작성일, 내용]
Apps Script 코드 미리 작성하고 실제로 테스트해보기
프롬프트 예시 슬라이드 정리 (복붙 가능한 형태로)
트러블슈팅 노트 준비 (자주 나오는 에러 4~5개 대응법)
스터디룸 와이파이 속도 체크 — 6명 동시 접속이 버티는지
여유 과제 카드 준비 (빨리 끝낸 사람에게 줄 다음 미션)

2. 참가자 사전 공지

노트북 + 충전기 (태블릿·휴대폰만으로는 진행이 어렵습니다)
크롬 브라우저 설치
Google 계정 (Sheets 연동에 필요)
GitHub 계정 (없으면 당일 만들어도 되지만 미리가 낫습니다)
사용할 AI 서비스 로그인 상태 확인
휴대폰 핫스팟 백업 준비 (와이파이가 막힐 때)

3. 당일 계정 세팅 순서

Replit 가입 — Google 계정으로 로그인하면 가장 빠릅니다
GitHub 로그인 확인 — 비밀번호 기억 안 나는 사람이 꼭 한 명 나옵니다
Vercel 가입 — 반드시 "Continue with GitHub"로
Google Sheets 템플릿 사본 만들기 (파일 → 사본 만들기)

4. 당일 준비물

완성본 URL — 화면에 띄워두고 시작
프롬프트 자료 — 채팅방 공유 또는 인쇄물
Sheets 템플릿 링크 (사본 만들기 권한 열려 있는지 확인)
발표 슬라이드
안내문 (오늘 흐름 · 링크 모음 한 장)

당일 진행 대본

구간마다 무엇을 말하고 무엇을 확인할지를 한 줄로 정리했습니다. 각 문서의 🎤 상자에 더 자세한 운영 요령이 있습니다.

시간할 일이 말은 꼭
15분 완성본 시연 → 세 단어(프론트·백·배포) 설명
README		 "오늘 코딩은 안 배웁니다. 말로 부탁하는 법을 배웁니다."
20분 계정 3종 생성 (Replit · GitHub · Vercel) "Vercel은 반드시 Continue with GitHub으로 가입하세요."
45분 화면 세 개 만들기
STEP 1		 "옆 사람과 화면이 달라도 정상입니다. 세 화면이 뜨면 성공이에요."
30분 Google Sheets 연동
STEP 2		 "여기서 절반은 한 번 막힙니다. 정상입니다."
20분 GitHub + Vercel 배포
STEP 3		 "다 함께 한 단계씩 갑니다. 먼저 가지 마세요."
나머지 커스터마이징 · Q&A
여유 과제		 "이 문서는 오늘 이후에도 그대로 남아 있습니다."
🎤 시간이 밀릴 때 자르는 순서

2~3시간은 생각보다 빠듯합니다. 밀리면 이 순서로 줄이세요.

  • 1순위로 자를 것 — 여유 과제. 원래 남는 시간용입니다.
  • 2순위 — STEP 1의 커스터마이징. 화면 세 개만 뜨면 다음으로 넘어갑니다.
  • 3순위 — STEP 2의 개별 해결. 진행자 웹앱 URL을 공유해 다 같이 같은 시트를 쓰게 하고 넘어갑니다.
  • 절대 자르지 말 것 — STEP 3 배포. 내 주소가 생기고 휴대폰에서 열리는 순간이 오늘의 하이라이트입니다. 여기까지 못 가면 만족도가 확 떨어집니다.
✱ 체크포인트 타이밍 — 네 번만 확인하세요

6명이 각자 다른 속도로 갑니다. 아래 네 지점에서 "다 되신 분 손 들어주세요"를 한 번씩 하면, 뒤처진 사람이 조용히 포기하는 걸 막을 수 있습니다.

  • ① 계정 생성 후 — Replit · GitHub · Vercel 세 개 모두 로그인 됐는지
  • ② 화면 완료 후 — 목록 · 글쓰기 · 상세보기 세 화면이 눈에 보이는지
  • ③ Sheets 연동 후 — 글을 하나 쓰면 스프레드시트에 행이 늘어나는지
  • ④ 배포 후 — 각자의 .vercel.app 주소로 실제 접속되는지
