준비 체크리스트

전날까지 이것만 해두면 됩니다

워크샵 당일에 시간을 잡아먹는 건 코딩이 아니라 계정 만들기와 로그인입니다. 아래만 미리 해두면 본 내용에 쓸 시간이 40분쯤 늘어납니다.

누가참가자와 진행자 모두. 참가자는 이 문서까지만 보시면 됩니다.
언제워크샵 전날까지
당일은진행 순서와 준비물은 당일 진행 문서에 따로 있습니다 (워크샵 당일 열림)
기록체크한 항목은 이 브라우저에 저장됩니다.

1. 전날까지 준비할 것

참가자에게 필요한 건 이게 전부입니다. 하나씩 눌러서 확인하세요.

노트북 + 충전기 — 태블릿·휴대폰만으로는 진행이 어렵습니다
크롬 브라우저 설치
Google 계정 로그인 — 스프레드시트 연동에 씁니다
GitHub 계정 — 없으면 당일 만들어도 되지만 미리가 낫습니다
AI 채팅 로그인 확인 — 평소 쓰시는 것 아무거나
무엇을 만들지 생각해오기 — 아래 안내문에 예시가 있습니다 (안 정해와도 됩니다)
✱ 계정을 미리 만들어두는 게 제일 큰 도움이 됩니다

당일 20분이 통째로 계정 만들기에 들어갑니다. 특히 비밀번호가 기억 안 나는 사람이 꼭 한 명 나옵니다. 전날 한 번씩 로그인해 보세요.

2. 참가자에게 보낼 안내문

진행자는 워크샵 3~4일 전에 아래 문구를 단톡방에 붙여넣으세요. 사이트 주소만 여러분 주소로 바꾸면 됩니다.

사전-안내문.txt
[비개발자 웹사이트 워크샵 안내]

코드 한 줄 몰라도 됩니다.
그날 안에 "내 주소가 있는 웹사이트"를 하나씩 만들어 갑니다.

■ 전날까지 준비해주세요
- 노트북 + 충전기 (태블릿·휴대폰으로는 진행이 어렵습니다)
- 크롬 브라우저
- Google 계정 로그인
- GitHub 계정 (없으면 당일 만들어도 됩니다)
- 평소 쓰시는 AI 채팅 로그인

■ 미리 생각해오면 좋은 것
"무엇을 기록하는 사이트를 만들까?"

기록하고 싶은 것 하나를 정해서, 네 칸으로 적어보세요.

  책 후기     → 제목 · 작성자 · 날짜 · 내용
  맛집 별점   → 가게 이름 · 추천인 · 별점 · 한줄평
  오늘의 기분 → 날짜 · 이름 · 기분 · 한 줄
  회비 장부   → 날짜 · 이름 · 항목 · 금액
  오늘의 질문 → 날짜 · 이름 · 질문 · 답

네 칸으로 적히기만 하면 무엇이든 됩니다.
못 정해도 괜찮아요. 당일에 같이 정합니다.

■ 준비 안내 페이지
아래 주소에서 준비물을 체크하실 수 있어요.

  (사이트 주소)/checklist.html

만드는 방법을 담은 나머지 문서는 워크샵 당일에 열립니다.

■ 이런 걸 배웁니다
문법이나 코드 읽는 법은 안 배웁니다.
"AI에게 원하는 걸 정확히 말하는 법"을 배웁니다.
⚠ 주제 정하기를 숙제로 만들지 마세요

미리 정해오면 당일 2분을 아끼고, 무엇보다 고민하느라 손이 멈추는 일이 없습니다. 하지만 "과제"처럼 느껴지면 부담 때문에 안 오는 사람이 생깁니다. "생각나면 하나 적어와 보세요" 정도가 딱 좋습니다.

🎤 진행자용 — 며칠 전에 해둘 것

참가자 준비물과 별개로, 진행자가 미리 만들어둬야 하는 것들입니다.

완성본 예제 사이트 배포해두기 (시연용 URL 확보)
Google Sheets 템플릿 준비 — 컬럼 [제목, 작성자, 작성일, 내용]
Apps Script 코드 미리 작성하고 실제로 배포까지 테스트해보기
Replit을 새 계정으로 한 번 돌려보기 — 신규 가입자가 보는 화면 확인
트러블슈팅 노트 준비 (자주 나오는 에러 4~5개 대응법)
주제 예시 표 띄워둘 준비 — 못 고르는 사람은 기본(책후기)으로
여유 과제 카드 준비 (빨리 끝낸 사람에게 줄 다음 미션)
사전 안내문 발송 (3~4일 전)

당일 준비물과 진행 순서는 당일 진행 문서에 있습니다.
